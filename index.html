Cantonese Audio (zh-HK) Voice Guide

This SPA strictly enforces lang = "zh-HK" in the browser's Web Speech API to prevent fallback to Mandarin standard Chinese pronunciation.

How to add Cantonese voice on your OS:

  • Windows 10/11: Settings → Time & Language → Language → Add a Language → Search "Chinese (Traditional, Hong Kong SAR)" → Install Text-to-Speech pack.
  • macOS / iOS: System Settings → Accessibility → Spoken Content → System Speech Voice → Manage Voices → Search "Cantonese (Hong Kong)" (e.g. Sin-ji or HiuGaai).
  • Android (Chrome): Settings → Accessibility → Text-to-speech output → Preferred engine settings → Install Voice Data → Cantonese (Hong Kong).

Once installed, refresh this page and the audio engine will automatically pair with your native Cantonese voice.

Pronunciation Guide

粵語六聲對照表 (Cantonese 6-Tone Audio Chart)

Cantonese is a 6-tone language using LSHK Jyutping (粵拼). Pitch numbers range from 1 (lowest) to 5 (highest). Click any tone card to hear native speech synthesis!

Tone 1 • 陰平 55 (High Level)

詩 si1

Poem (High flat note)

Tone 2 • 陰上 25 (High Rising)

史 si2

History (Rising pitch)

Tone 3 • 陰去 33 (Mid Level)

試 si3

Try / Test (Mid flat note)

Tone 4 • 陽平 21 (Low Falling)

時 si4

Time (Low falling note)

Tone 5 • 陽上 23 (Low Rising)

市 si5

Market / City (Low rising)

Tone 6 • 陽去 22 (Low Level)

事 si6

Matter / Event (Low flat)
