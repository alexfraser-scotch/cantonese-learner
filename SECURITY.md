# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security vulnerability within **Cantonese Vocabulary Learner**, please report it responsibly:

1. **Email:** Send details directly to security@swiftflowdigital.com or create a private security advisory on GitHub.
2. **Details to Include:**
   - A clear description of the vulnerability.
   - Steps or proof-of-concept scripts to reproduce the issue.
   - Potential impact of the issue.

Please do not disclose security issues publicly in public GitHub issues until a patch has been released. We aim to acknowledge reports within 48 hours and provide a fix promptly.
